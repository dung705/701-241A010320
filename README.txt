# Website 701-MSSV

## Cấu trúc
- index.html: menu chính
- lythuyet.html: trả lời lý thuyết
- baitap22.html: form đăng ký
- baitap23.html: countdown timer
- diemdanh.html: thông tin điểm danh
- baitap01.html, baitap02.html, baitap03.html: trang mẫu
- about.html, contact.html
- css/style.css, js/script.js

## Trước khi nộp
1. Đổi tên thư mục `701-MSSV` thành tên đúng theo yêu cầu của giảng viên, ví dụ `701-22123456`.
2. Cập nhật họ tên, MSSV, lớp, học phần và URL deploy trong `diemdanh.html`.
3. Kiểm tra số thứ tự bài 22/23 có đúng với đề thực tế không; hiện tại bài 22 là form đăng ký và bài 23 là countdown timer.
4. Deploy thư mục lên GitHub Pages hoặc Netlify.
